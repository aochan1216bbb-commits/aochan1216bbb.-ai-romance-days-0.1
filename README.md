## 方針
- キャラクター基本設定を `characters/<id>.js` へ完全分離。
- 絵里香の依存・嫉妬系ヘルパーを `erika.js` へ移動。
- 結衣の体型変化専用定義を `yui.js` へ移動。
- 絵美の大規模専用システムは `emi_systems.js` としてキャラクターフォルダへ隔離。
- 共通システムには `systems/` の安定した窓口を追加。
- v36のゲーム挙動を極力維持しながら、今後はキャラ固有実装を共有ファイルへ増やさない構造に変更。

## 今後の実装ルール
1. キャラ固有のイベント・口調・状態補正は `characters/` に追加。
2. 全キャラ共通の計算だけ `systems/` または共有ファイルへ追加。
3. 共通処理からキャラ固有処理が必要な場合は `CharacterHooks` を利用。
4. `index.html` は起動とUI構造に限定して肥大化させない。

## v42 絵美：挫折・余裕モデル
- Lv1〜7ごとに「成功体験しかなかった陸上選手が、体型変化という初めて制御できない問題に直面する」心理変化をAIプロンプトへ追加。
- Lv3から自分への言い聞かせ、Lv4から努力が結果につながらない混乱、Lv5から苛立ち、Lv6以降は退部に伴う後悔・喪失感を強化。
- 体型Lvだけでなく、機嫌・競技コンディション・食への興味・ダイエット中か・退部済みかを使って心理的余裕を動的判定。
- 余裕低下時は主人公への問いかけより、独り言・自分への苛立ち・言葉に詰まる反応を優先。
- Lv4以降、服トラブル・鏡・昔の記録・スパイク・陸上動画など失敗/比較イベントの機嫌低下を強化。
